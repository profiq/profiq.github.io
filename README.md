# profiq.github.io

Static site served at <https://profiq.github.io/>.

## Coding challenge gallery

Example single-file minigames for the Summer Coding Challenge 2026. Each app is a
self-contained `index.html` that runs in any browser.

- `index.html` — gallery landing page
- `blastman/` — BLASTMAN, a single-screen Bomberman (1–2 players)
- `leap/` — LEAP, a one-button endless runner

No build step. Push to the default branch and GitHub Pages serves it.
