Example app gallery

The challenge asks for a complete minigame delivered as one index.html that runs in any browser — generated from a single prompt, no manual edits. Here are a couple built to that spec so you can see what "done" looks like.

  • BLASTMAN

    BLASTMAN

    Drop bombs · break walls · survive

    A single-screen Bomberman built for 1 or 2 players. Trap the enemies (or each other) in the blast radius, grab power-ups, clear the board.

    Keyboard · P1 WASD + Space, P2 arrows + Enter
